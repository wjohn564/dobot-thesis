# Dobot Robotic Sorting Thesis Project

This repository contains the code and notebooks for my MSc thesis comparing object detection methods for robotic block sorting.

## Detection Methods

- OpenCV HSV colour segmentation
- YOLO26n
- Faster R-CNN MobileNetV3-Large 320 FPN
